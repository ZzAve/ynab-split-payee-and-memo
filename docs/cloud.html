Run in the cloud

No laptop required — run the splitter on a schedule with Scaleway Serverless Jobs.

1
Getting ready

Prerequisites

Before you start, make sure you have these two things in place.

  • A Scaleway account with a project in the Paris or Amsterdam region.
  • A YNAB Personal Access Token. If you don't have one yet, see the usage guide for how to create it.
2
Set it up

Create the job

In the Scaleway Console, navigate to Serverless → Jobs and create a new job definition.

Set the image source to the public Docker image:

Image reference

docker.io/zzave/ynab-split-payee:latest

For resources, 1 vCPU and 256 MB RAM is more than enough. The job typically finishes in a few seconds.

3
Configure

Environment variables

Add the following environment variables to your job definition. Only the token is required — the rest are optional.

YNAB_TOKEN Required
Your YNAB Personal Access Token. This is how the tool authenticates with the YNAB API.
YNAB_BUDGET_ID
Target a specific YNAB budget. If omitted, the tool uses your last-used budget.
YNAB_ACCOUNT_ID
Only process transactions from a specific account. If omitted, all accounts are processed.
YNAB_BUDGET_IDS
Comma-separated list of budget IDs to process multiple budgets in one run. Cannot be used with YNAB_BUDGET_ID.
Tip

Use Scaleway's secret management to store your YNAB token rather than adding it as a plain-text environment variable.

4
Schedule

Cron trigger

Add a cron trigger to your job so it runs automatically. Every hour is a good default — frequent enough to catch new imports quickly, light enough to stay well within free-tier limits.

Cron expression (every hour)

0 * * * *
Note

Scaleway cron triggers use UTC. If you'd rather run it at a specific local time (e.g. every morning at 8 AM), adjust the hour accordingly.

5
Confirm

Verify

Before relying on the schedule, trigger a manual run from the Scaleway console to make sure everything is wired up correctly.

  • Trigger a manual run from the job detail page in the Scaleway console.
  • Check the run log for exit code 0. If you see errors, double-check your token and environment variables.
  • Open YNAB and confirm that your transactions were processed — payees should be clean, memos filled in.

Once the manual run looks good, the cron trigger will take care of the rest. Your transactions will be cleaned up automatically, whether your laptop is on or not.
